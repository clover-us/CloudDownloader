# CloudDownloader 0.6.4

0.6.4 重构了「我的网盘」的文件管理器界面，并补齐了批量操作、排序筛选、文件夹上传与迅雷新建文件夹等能力；同时把「下载文件夹」改为后台解析，解决了点击下载后长时间转圈的问题。

## 更新内容

- 全新文件管理器式「我的网盘」：顶部批量栏显示「已选中 N 项 / 取消选中 / 下载 / 分享 / 删除 / 更多」，每一行悬浮显示针对该文件或文件夹的操作按钮（下载、分享、重命名、删除），未适配的操作置灰。
- 统一工具栏：左侧网盘名称与搜索框，右侧提供上传、新建文件夹、排序、列表 / 网格切换、筛选与刷新。搜索、排序、筛选的布局与交互参照文件管理器习惯。
- 上传菜单：上传按钮悬浮展开「上传文件 / 上传文件夹」。选择文件夹上传时会保留原始子目录结构，逐级在云端创建目录并归档文件，同时显示目录级上传进度。
- 排序面板：支持按修改时间、创建时间、文件名称、文件大小排序，每种字段均支持正序与倒序；文件夹始终排在最前。
- 筛选面板：可按文件类型筛选（全部类型、视频、音频、图片、文本、字体、字幕、安装包、压缩包、BT 种子、其他），支持多选、重置、取消与确认。
- 全库排序与筛选：新增后端聚合接口，跨分页读取整个目录后再排序 / 筛选（上限 2 万项，超出时标记为已截断），不再只作用于当前已加载的一页。
- 面包屑导航：单行显示、左对齐，过长时右侧省略；层级较多时自动折叠为「全部文件 > … > 末两级」，悬停可查看被折叠的层级。
- 迅雷网盘新增「新建文件夹」：与百度网盘一致，可在当前目录创建文件夹。
- 创建时间：为各网盘补充「创建时间」字段，供排序与显示使用；部分接口不返回创建时间的网盘会回退为修改时间。
- 下载文件夹更快：点击下载后立即返回并把任务加入列表，逐个文件在后台解析下载地址，任务列表实时更新；不再因文件夹内容较多而长时间卡在按钮转圈。
- 能力适配：夸克、百度、迅雷优先完善。所有网盘均支持浏览与下载；上传支持百度与迅雷；新建文件夹支持百度与迅雷；创建分享支持百度；重命名与删除暂未开放，界面中置灰。
- 兼容 0.6.x 的账号管理、我的网盘、设置中心与应用内自动更新。

## 说明

上传文件夹会按本地相对路径在云端逐级创建同名目录；若云端已存在同名目录会复用，不会重复创建。云端文件的重命名与删除接口尚未接入，对应按钮暂时置灰。自动更新仅对安装版生效，便携版需手动下载新包。
