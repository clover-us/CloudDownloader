# CloudDownloader 0.7.7

接力确认窗里的长链接改成缩略显示，并修掉「用浏览器下载」会把链接再接管一次的循环。

## 改进

- **链接缩略展示**：下载链接不再整条铺开，改成 `主机名/…/文件名` 的超链接样式，悬停可看完整地址。单击在浏览器打开，双击复制链接，复制后短暂显示「已复制链接」。
- **修掉接管循环**：确认窗里选「用浏览器下载」（或单击链接）会让浏览器重新开始这个下载，而扩展立刻又会把它交回应用，来回弹窗。现在应用在把链接交回浏览器前会先告诉本机桥「这条放过」，扩展看到 `taken: false` 就保持浏览器下载不动，一分钟内有效。

## 说明

- 扩展版本升到 **0.2.1**，需要重新加载一次扩展（`edge://extensions` 里点「重新加载」）；旧版扩展不认识 `taken: false`，仍会出现一次循环。
- 应用其余行为不变；15 秒无操作仍默认交给应用。
