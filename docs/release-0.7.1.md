# CloudDownloader 0.7.1

0.7.1 修掉两个 0.7.0 带出来的问题：安装或自动更新时 `bin\aria2c.exe` 被占用导致安装失败，以及插件面板里「打开扩展文件夹」按钮点了报权限错误。

## 修复

- **安装时 aria2c 被占用**：安装器现在先关闭 CloudDownloader 主程序，再按安装目录范围停掉下载引擎，并等到 `bin\aria2c.exe` 真正可写之后再解包。之前只杀引擎不关主程序，应用会立刻把引擎重新拉起来，于是又撞上文件占用。
- **「打开扩展文件夹」报 ACL 错误**：插件面板调用 `open_path` 缺少对应权限声明，现在已加入 capability，可以正常打开扩展目录。

## 说明

- 这次更新会由 0.7.0 的自动更新流程安装；如果本机正在下载，安装前请让任务先暂停，安装器会关闭主程序和引擎。
- 扩展本身没有变化，仍是 0.2.0。
