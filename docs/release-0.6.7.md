# CloudDownloader 0.6.7

0.6.7 重做了下载与上传两个任务列表：网盘文件夹下载、文件夹上传合并为一条任务记录，表头提供批量暂停、继续、移除与清除已完成；「我的网盘」搜索框在所有网盘上统一，并改为服务端递归搜索当前目录及子目录。同时修复文件夹下载长时间停在「获取地址」、暂停文件夹只暂停一个文件、继续后进度条清空等问题，设置中的数字输入框新增框内悬浮加减箭头。

## 更新内容

### 下载管理

- **文件夹任务合并为一行**：在「我的网盘」选择一个文件夹下载后，下载列表只出现一条该文件夹的任务，显示文件夹总进度、总速度与已完成文件数；点击左侧箭头展开查看各文件子任务，也可在文件夹层级直接暂停、继续、移除或打开下载目录。再次下载同一文件夹会并入原任务组，不会重复创建。
- **批量操作**：列表表头新增全选与「已选中 N 项 / 取消选中 / 暂停 / 继续 / 移除」操作条，全选时文件夹按一个任务计数；「已完成」筛选下提供「清除已完成」。批量操作会跳过当前状态不适用的任务并提示数量，不再逐条报错。
- **文件夹解析提速**：同一批任务共享一次网盘会话，并以 3 路并发解析下载地址，不再为每个文件单独打开隐藏 WebView；大文件夹不会再长时间停留在「获取地址」。
- **暂停与继续修复**：暂停文件夹时会同时暂停仍在解析地址的文件，重复点击不再弹出 `cannot be paused now`；继续任务改用引擎原生恢复，已下载进度不会先清零再恢复，仅在需要重新取链时才重建任务。

### 上传任务

- **批量操作**：上传任务表头新增全选与批量暂停、继续、移除，以及「已完成」筛选下的「清除已完成」。
- **下载中筛选**：筛选栏改为「全部 / 下载中 / 已完成 / 已暂停 / 失败」，「下载中」包含排队、校验、传输与提交中的任务。
- **文件夹上传合并为一行**：上传整个文件夹时，任务列表只显示一条文件夹记录，聚合显示进度与速度；展开可查看单个文件，文件夹层级同样支持暂停、继续与移除。

### 我的网盘

- **统一搜索**：所有网盘使用与百度网盘一致的搜索框（图标 + 输入框 + 搜索按钮），不再区分「筛选已加载的文件」。夸克、迅雷、115、123、139、UC 与蓝奏系网盘改为在服务端递归搜索当前目录及子目录（并发 4 路，最多 400 个目录、2 万项、1000 条结果，超出时提示已截断）。百度仍使用官方目录搜索接口。
- 搜索框宽度略微收紧，与网盘标签之间留出间距。

### 设置与界面

- 设置中的六个数字输入框改为居中显示，并在框内右侧新增悬浮上下箭头：单击加减一步，按住连续加减，`PageUp` / `PageDown` 一次加减五步；同时隐藏系统原生数字箭头。
- 统一下载、上传与网盘三处列表的表头高度、左右内边距与图标列，文件夹展开箭头移入左侧留白；任务卡片圆角与表头贴合，滚动条不再压住表头右上角。

### 修复

- 继续暂停中的任务时进度条短暂清空的问题。
- 文件夹下载暂停后仍有子任务继续启动的问题。
- 文件夹上传与文件夹下载在列表中散开为大量单文件行的问题。

## 说明

- 文件夹任务记录沿用本机任务数据库，升级后历史任务仍按单文件显示，新发起的文件夹下载才会合并。
- 迅雷网盘个别文件仍可能返回「迅雷未返回可用的下载地址」，与网盘侧的取链限制有关，可稍后重试或改用其他方式获取。
- 文件删除不可恢复，删除任务时默认只移除记录；勾选「同时删除本地文件」才会清理本地文件。
