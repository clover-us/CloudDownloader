# CloudDownloader 0.7.6

接力确认之后直接开始下载，不再把链接留在下载框里等第二次点击。

## 改进

- **确认即入队**：在接力确认窗点「交给 CloudDownloader」后，应用立刻识别链接、按浏览器带来的文件名和请求头建任务并开始下载，下载框会随之清空。文件名、Cookie、来源站点、浏览器标识都照旧带上。
- **识别结果落定再开始**：接力进来的链接会被输入框的识别逻辑再触发一次，开始下载前会等结果稳定，避免用空的识别结果去建任务。

## 说明

- 「用浏览器下载」「忽略」的行为不变；15 秒无操作仍默认交给应用。
- 扩展本身没有变化，仍是 0.2.0。
