# CloudDownloader 0.7.5

浏览器接力不再直接往下载框里塞链接，而是先弹一个确认窗：看清楚是哪个文件、从哪个站点来的，再决定交给应用还是留在浏览器里。

## 新增

- **接力确认窗**：浏览器把下载交给应用时会弹出小窗，显示文件名、完整链接和来源站点，三个选择：
  - 「交给 CloudDownloader」：进入新建下载，预填并识别链接；
  - 「用浏览器下载」：把链接交回默认浏览器重新下载（浏览器那份已经被扩展停下，所以要重新开始）；
  - 「忽略」：什么都不做。
- **默认动作**：15 秒没有操作就按「交给 CloudDownloader」处理，窗口标题上的倒计时会显示剩余秒数。想改成默认留在浏览器或一直等待，改一个常量即可。
- 来源站点从扩展带来的 `Referer` 头里取，取不到时显示「来源未知」。

## 说明

- 扩展本身没有变化，仍是 0.2.0；确认发生在应用侧。
- 安装与升级沿用 0.7.2 的改动：引擎从 `%LOCALAPPDATA%\CloudDownloader\engine\` 运行。
