# CloudDownloader 0.7.0

0.7.0 把「浏览器里的下载」接进了应用：网页上点下载会交给 CloudDownloader，Cookie、来源页面和浏览器标识一起带过来，需要登录才能取的直链也能直接下；标题栏新增插件按钮，随时能检测扩展是否在工作。

## 更新内容

### 浏览器接力

- **网页下载交给应用**：装好扩展后，在浏览器里点下载会取消浏览器自己的传输，改由应用接手，进度、续传、限速都在一个地方管理。
- **带上登录信息**：扩展把当前页面的 Cookie、Referer 和 User-Agent 一并交给应用，需要登录的直链不再 401；这些信息只用于这一次请求，不写日志也不保存。
- **直链协议**：`clouddownloader://add?url=...` 可以从任何地方把链接丢进应用。
- **接力可见**：任务列表会标出「浏览器接力」和来源站点；没接住时浏览器弹一条通知说明原因，浏览器自己的下载照旧完成，不会两头落空。
- **标题栏插件按钮**：显示扩展心跳、监听端口与版本，一键打开扩展目录、复制安装步骤、重新检测。
- **端口可配**：默认 17890，被占用时在设置里换一个，本机桥会立刻换端口。

### 下载

- **直链默认 8 路连接**：这类 CDN 在 16 路时容易丢 TLS 握手；握手失败会自动按 8 → 4 → 1 降级重试。
- **续传修复**：点「继续」时清理旧任务不再删除 `.aria2` 控制文件，避免进度被悄悄丢掉。

### 扩展与分发

- 扩展签名并固定 ID（`bgmhpiikmknhjbgpedfgpelffapcagpa`），打包脚本同时产出 zip 与 CRX。
- 本机桥托管 `update.xml` 与 `extension.crx`，企业策略可以直接指向它安装。
