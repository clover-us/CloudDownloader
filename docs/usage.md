# 使用指南

下载 [v0.6.7 Release](https://github.com/clover-us/CloudDownloader/releases/tag/v0.6.7)：[Windows 安装版](https://github.com/clover-us/CloudDownloader/releases/download/v0.6.7/CloudDownloader_0.6.7_x64-setup.exe) · [便携版](https://github.com/clover-us/CloudDownloader/releases/download/v0.6.7/CloudDownloader-0.6.7-win-x64.zip) · [SHA-256 校验](https://github.com/clover-us/CloudDownloader/releases/download/v0.6.7/SHA256SUMS-0.6.7.txt)。

1. 推荐运行 `CloudDownloader_0.6.7_x64-setup.exe` 中文安装包，默认安装到当前用户目录并创建快捷方式，缺少 WebView2 时会从微软下载运行时。也可解压便携版压缩包后运行 `CloudDownloader.exe`，移动时保留完整目录结构。
2. 「新建下载」只有一个输入框：粘贴 HTTP/HTTPS 文件直链、网盘分享文字或 `magnet:?xt=urn:btih:…` 磁力链接，程序自动识别类型，点击「解析链接」预览文件。也可点击「导入种子」选择本地 `.torrent` 文件，种子的 HTTP/HTTPS 地址直接粘贴即可。
3. 网盘分享自动识别提取码，可手动补充。需要登录的网盘在官方窗口自行完成登录；蓝奏云、优享版和 UC 分享可先尝试免登录，服务端要求登录时再连接账号。
4. 普通文件可改文件名及连接数；网盘和 BT 可以选择文件，网盘还可浏览子文件夹。确认保存目录后点击「开始下载」。磁力解析可取消，获取元数据阶段不下载文件内容。
5. 任务支持暂停、继续、重试；文件夹下载与文件夹上传在列表中合并为一行，展开可查看子任务。列表表头提供全选、批量暂停 / 继续 / 移除，以及「已完成」筛选下的「清除已完成」。程序退出再启动后，未完成任务保持暂停；继续时重新核对下载来源。
6. 点击窗口右上角关闭按钮默认收进系统托盘，传输继续运行。点击托盘图标或右键选择「打开主窗口」恢复窗口；右键选择「退出程序」才会结束程序与下载引擎。「设置 → 通用」可把关闭行为改为直接退出。

需要 Windows 10/11 x64 和 Microsoft Edge WebView2 Runtime。下载引擎位于 `bin/aria2c.exe`，程序按主 EXE 所在目录定位引擎，不依赖启动时的工作目录。第三方许可资料位于 `bin/notices/`。

## 主题切换

- 标题栏右上角、最小化按钮左侧的月亮／太阳按钮可在蓝白日间主题和 Night 主题间切换，自动记住选择，重启后恢复。
- Night 主题统一覆盖导航、文件列表、传输任务、输入框和弹窗；主题仅影响本程序主窗口。
- 浅蓝导航、白色工作区和蓝色操作按钮，下载、网盘、上传、分享及弹窗使用统一配色。
- 移除原有游戏文案、角色立绘与切换功能，文件列表使用完整内容宽度。
- 窗口标题栏、应用图标和托盘提示与通用下载工具风格保持一致；窄窗口及较低窗口高度下自动调整布局。

## 设置与自动更新

- 左侧「设置」分为四组：通用（下载目录、关闭窗口行为）、传输（全局限速、同时下载数、默认连接数）、外观（日间 / Night）与关于。
- 所有改动即时保存：限速与同时下载数通过 aria2 的全局选项立即生效，正在下载的任务不会被中断；默认连接数用于之后新建的普通链接任务。
- 全局限速填 0 表示不限速，单位为 MiB/s；也可点击 1 / 5 / 10 MiB/s 快捷项。同时下载数的可填范围是 1–10。数字输入框右侧有悬浮上下箭头：单击加减一步，按住连续加减，`PageUp` / `PageDown` 一次加减五步。
- 「关于与更新」显示当前版本，可手动检查更新、查看进度并下载安装。安装完成后点击「立即重启」即可换到新版本，任务与登录状态都会保留。
- 默认开启「启动时静默检查更新」，发现新版本时「设置」菜单会显示小圆点，不影响正在进行的下载。
- 自动更新只对安装版生效：便携版和 `tauri dev` 开发模式不会自我替换，需要手动下载新包。
- 「打开目录」可以直接定位到 `%APPDATA%\com.sixunited.clouddownloader`，其中保存账号配置、任务数据库与种子缓存。

## 个人网盘下载

- 在「我的网盘」顶部切换夸克、百度、迅雷、115、123、139、UC、蓝奏云、蓝奏云优享版。点击「打开网盘」，在对应官方窗口完成登录后刷新文件列表。
- 文件列表按窗口剩余高度滚动，顶部批量栏显示「已选中 N 项 / 取消选中 / 下载 / 分享 / 删除 / 更多」，每一行悬浮显示下载、分享、重命名、删除等操作，未适配的操作置灰。
- 工具栏右侧提供上传、新建文件夹、排序、列表 / 网格切换、筛选与刷新。排序支持修改时间 / 创建时间 / 文件名称 / 文件大小正反序；筛选支持按文件类型多选；排序与筛选作用于整个目录（跨分页聚合，上限 2 万项，超出时提示已截断），不再只过滤当前页。
- 支持进入文件夹、面包屑返回、分页加载，选择文件或文件夹下载。面包屑单行显示、过长时右侧省略，层级较多时折叠为「全部文件 > … > 末两级」。工具栏搜索框在所有网盘上一致：输入关键词后点击「搜索」，递归查找当前目录及子目录（上限 400 个目录、2 万项，结果超过 1000 条时提示已截断）；百度网盘使用官方目录搜索接口。清空关键词后再次搜索可退出结果列表。
- 一次最多选择 100 项，文件夹递归展开最多 10000 项，按云端层级保存到本地。空文件夹不单独创建。
- 下载任务绑定创建时的账号，恢复时重新读取文件信息并获取临时下载地址。账号切换、源文件大小或校验信息变化时阻止续传。
- 115 使用客户端加密取链；123 使用网页登录令牌和请求签名；139 的分享接口使用加密请求；迅雷复用网页登录的 Bearer 登录令牌与客户端签名（含验证码令牌）；无需用户填写开发者密钥或复制 Cookie。
- 迅雷网盘支持个人文件浏览、文件下载与分享链接解析下载；在「我的网盘」目标目录可上传本地文件（分片直传对象存储）、新建文件夹、创建分享，上传失败可在「上传任务」中重试。登录窗口关闭后账户仍保持连接。
- 百度、夸克、迅雷网盘支持对文件或文件夹「重命名」和「删除」：选中后点击批量栏或行内按钮即可操作，删除前会列出待删除项并提示无法恢复。百度、夸克、迅雷均支持「上传」本地文件、「新建文件夹」与「创建分享」（可选 1/7/30 天或永久有效期和 4 位提取码；夸克与迅雷的提取码由网盘生成）。其他网盘目前仅支持浏览与下载，未适配的操作仍置灰。
- 点击「下载」后任务会立即加入列表，程序在后台复用同一网盘会话并发解析下载地址并更新任务状态，不需要等待整个文件夹解析完成。选中的文件夹在下载列表中只占一行，显示文件夹总进度与总速度；点击左侧箭头展开子任务，文件夹层级可直接暂停、继续、移除或打开下载目录。再次下载同一文件夹会并入原任务，不会重复创建。暂停文件夹会同时暂停仍在解析地址的文件。

## UC 与蓝奏云

- UC 在官方网页登录；个人网盘和分享下载分别使用对应通道，分享遇到游客大小上限时提示登录。下载请求使用 UC 的 Referer 和当前下载会话。
- 普通蓝奏在 `pc.woozooo.com` 登录，读取文件及文件夹分页；个人文件下载读取文件已有的外链信息，再解析下载地址，不修改云端文件、密码或分享设置。
- 普通蓝奏支持常见 `lanzou` 域名族的单文件、文件夹及提取码分享。下载前检查真实文件内容类型和大小，验证页面会提示处理。
- 优享版在 `www.ilanzou.com` 登录，复用官方网页的 appToken，并保存非敏感设备标识；使用独立的个人盘和分享接口。程序不接收或保存账号密码。
- 三个新增网盘已完成模拟协议回归；真实账号、分享提取码、服务端验证和会员下载行为尚需使用自己的账号验证，详见[验证记录](../VERIFICATION.md)。

## 我的网盘：上传、分享与文件管理

- 复用百度官方网页登录状态，不需要开放平台 API Key。打开「我的网盘」可进入文件夹、使用路径栏、分页加载和搜索当前目录及子目录。
- 选择文件或文件夹直接下载到本地；文件夹会递归展开，任务归入原下载队列。恢复下载时核对账号、文件 ID、大小与校验信息。
- 0.4.1 修复个人网盘大文件可能在 0 B 时失败的问题：通过文件元数据接口获取有效下载地址；HTTP 拒绝、链接不存在、限流和服务器异常会显示对应提示。
- 在目标文件夹点击「上传文件」，一次最多选择 100 个本地文件。确认文件列表、目标目录和并发数后开始。支持创建目标文件夹。
- 可从资源管理器将本地文件拖到「我的网盘」当前目录、列表中的文件夹或路径导航中的文件夹。拖动时高亮目标并显示完整路径，松开即加入上传队列；默认每文件分片并发 4 路、同时上传 2 个文件，均可在「设置 → 传输」中调整。同样支持一次最多 100 个文件，暂不支持拖入本地文件夹。
- 上传分片大小默认 8 MiB（1–32 MiB 可调）；百度 PCS 按协议固定 4 MiB，迅雷/夸克使用对象存储分片。分片并发默认 4 路（1–16 可调），同时上传数默认 2（1–8 可调）。失败分片重试最多 3 次（共 4 次尝试），每次核对分片 MD5。
- 进度实时刷新：百度按已确认的分片计算，迅雷/夸克按已发送字节计算，均显示速度和估算剩余时间。支持暂停、继续、重试和移除记录；重启后未完成任务保持暂停。迅雷/夸克大文件分片会记录已完成分片，继续时只补传缺失分片；分片协议失败时自动回退整文件上传。
- 「上传任务」页可按「全部 / 下载中 / 已完成 / 已暂停 / 失败」筛选；表头支持全选、批量暂停 / 继续 / 移除，以及「已完成」下的「清除已完成」。上传整个文件夹时只显示一条文件夹任务，展开可查看单个文件，文件夹层级同样支持暂停、继续与移除。
- 同名文件会自动追加序号（如 `name (1).ext`），不会覆盖；同一文件重复提交会被拦截。任务绑定创建时的网盘账号，账号切换或本地文件变化会阻止继续上传。
- 点击「创建分享」，确认所选文件、1/7/30 天或永久有效期和 4 位提取码；成功后可复制链接。永久链接在分享记录中显示「永久有效」，不会因时间推移被标记为过期。在「分享记录」中可取消本程序创建的分享，网盘文件会保留。
- 「分享记录」是本机记录，不同步其他客户端创建的分享；外部取消等状态以百度页面为准。

当前上传支持选择多个文件，或上传整个文件夹（保留本地子目录结构，逐级在云端创建目录并显示目录级进度）；自动同步不在此版本中。上传、新建文件夹、创建分享、重命名与删除均已支持百度、夸克、迅雷（夸克与迅雷的提取码由网盘生成），其他网盘暂未适配。

## 普通链接多连接下载

- 支持 HTTP/HTTPS 文件直链、服务器重定向和自动识别文件名，也可手动填写文件名。已有同名文件自动编号，保留原文件。
- 默认最多 16 路连接，可选择 1、4、8、16 路；使用 aria2 分段并行传输，任务显示实际连接数。小文件可能无需全部连接，实际速度取决于服务器限速和网络。
- 创建和恢复时检测分段支持。支持分段的服务器可暂停续传；不支持分段时使用单连接，恢复会从头重新下载该任务的未完成文件，界面会说明。
- 已下载部分内容时，会核对可用的文件大小、ETag 或最后修改时间，发现来源变化则阻止续传。链接过期或需要网站登录时，获取有效直链后新建任务。
- 普通下载不使用网盘账号、Cookie 或登录资料。文件直链保存在本机任务记录中以便恢复；无需登录的下载地址可以直接使用。

## BT 与磁力下载

- 支持 BT v1 磁力链接（40 位十六进制或 32 位 Base32 btih）、本地 `.torrent` 和 HTTP/HTTPS 种子地址。支持 v1/混合种子，暂不支持纯 BT v2。种子大小上限 4 MiB，最多 10000 个文件；文件名需为 UTF-8 且兼容 Windows。
- 磁力链接先向 Tracker/DHT 节点获取元数据，再显示文件列表；无在线节点时无法获取，约三分钟超时，可取消或改为导入种子。解析不等同于已经下载文件。
- 选择部分或全部文件后创建一个 BT 任务，默认最多连接 64 个节点，可设 1–500；BT 使用节点连接，独立于 HTTP 的每服务器 16 路连接上限。
- 下载期间会上传分片，默认每任务上传上限 512 KiB/s，填 0 表示不限。默认下载完成后停止，也可选继续做种 30 分钟、1 小时或 24 小时。
- 每个种子使用独立的任务文件夹，保持种子内的层级和文件名，避免覆盖其他下载。跨文件的校验分片可能写入少量未选择的相邻文件数据。
- 任务支持暂停、继续和退出重启后续传；恢复时重新验证种子缓存与已下载分片。进度按所选文件和已校验分片计算，显示节点数及上传速度。
- 「同时删除本地文件」只清理该种子清单中的下载文件、相邻分片文件及续传信息，保留额外放入的其他文件和导入的原始种子。未勾选时下载文件保留。
- 元数据缓存在 `%APPDATA%\com.sixunited.clouddownloader\bt-torrents\`，用于重启续传；私人 Tracker 地址可能包含在种子元数据中，请勿公开缓存文件。

## 从浏览器发送链接

- 应用会注册 `clouddownloader://` 协议。把链接交给应用后，主窗口会回到前台、自动填好链接并立即识别类型；确认文件后再点「开始下载」，不会跳过预览直接下载。
- 命令行或网页里的写法（链接需要 URL 编码）：

```powershell
start "clouddownloader://add?url=https%3A%2F%2Fexample.com%2Ffile.zip"
```

- 支持 HTTP/HTTPS 直链和 `magnet:` 磁力链接；其他协议、本地文件路径和多条链接会被忽略。
- 协议在应用每次启动时写入当前用户注册表（`HKCU\Software\Classes\clouddownloader`），卸载时删除。便携版换了目录后启动一次即可重新指向新的可执行文件。
- Chrome/Edge 首次点击会询问是否打开 CloudDownloader，勾选「始终允许」后不再提示。网页里点下载按钮直接开始的普通文件下载不会被接管，那需要浏览器扩展，当前版本尚未内置。

## 账号与下载

- 九个网盘使用独立的 WebView2 登录资料，下载任务标注来源。115 额外使用当前 Windows 用户的 DPAPI 加密保存登录 Cookie，并在打开官方页面前恢复会话，同一网盘的并发请求会等待恢复完成；正常退出时再次保存，网页登录账号退出后清除缓存。升级后请登录一次以建立该缓存，服务端使登录失效时仍需重新登录。
- 支持目录分页、文件夹递归下载、同名文件编号、Windows 文件名清理。
- 最多同时下载 3 个文件；九个网盘的分享及个人网盘下载每文件最多 16 路连接，最小分段 1 MiB，普通链接按所选连接数下载。
- 记录保存在 SQLite；网盘账号 Cookie、网页登录令牌和网盘临时下载地址不写入任务记录。123 的随机设备标识保存在本机设置中，跨重启保持一致。
- 密码和验证码只在官方页面中输入。网页登录会话只用于对应网盘的请求。
- 下载引擎只监听本机，每次启动使用随机 RPC 密钥，并随主程序退出。
- 删除下载任务时可选择「同时删除本地文件」，默认不勾选。未勾选时只停止下载并移除记录，保留本地文件与续传信息；勾选后会永久删除该任务已下载或未完成的文件及对应 `.aria2` 文件。
- 删除前先确认引擎已停止写入。文件被占用、路径异常或文件还被其他任务使用时，会保留任务记录并提示原因，可处理后重试；不会递归删除下载目录或其他文件。上传记录仍只移除记录，保留本地源文件和网盘文件。

实际速度、会员权限、分享有效期、验证码和是否允许分享直接下载由网盘服务端决定。程序不会自动转存或删除云盘文件。当前适配网页接口，并非各网盘承诺稳定的公开 SDK，接口变化可能需要更新。各网盘实际验证进展见[验证记录](../VERIFICATION.md)。

UC、蓝奏云、蓝奏云优享版参考 [CYQawa/YunX](https://github.com/CYQawa/YunX) 的解析、登录凭据及下载接口流程，以 Rust 实现适配器；此前网盘参考 [YunX-Desktop](https://github.com/tidain/YunX-Desktop)。参考版本和许可出处列在 [协议参考与许可出处](../third-party/notices/cloud-protocol-sources.txt)，未随包包含其程序或 Kotlin 源文件。

## 从 QuarkDownloader 迁移

首次运行且新资料目录不存在时，程序使用 SQLite 备份接口复制旧数据库（包含 WAL 中的数据），并复制夸克登录资料。完整复制后再启用新目录，原资料保留。旧任务视为夸克任务，下载目录和未完成文件的位置不变。

升级前请关闭旧版 QuarkDownloader。迁移完成后使用新版继续下载；不要同时运行两个版本操作同一下载文件。

- 新登录资料和数据库：`%APPDATA%\com.sixunited.clouddownloader\`
- 旧资料保留：`%APPDATA%\com.sixunited.quarkdownloader\`
- 全新安装的默认下载目录：`%USERPROFILE%\Downloads\CloudDownloader\`
- 迁移用户继续使用原先选择的下载目录。
- `.aria2` 文件保存续传信息，任务完成前请保留。
