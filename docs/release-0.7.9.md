# CloudDownloader 0.7.9

这一版是安全加固与稳定性修复：收紧了浏览器接力的连接与来源校验，修掉了几处会让界面卡死或丢任务状态的路径，并清理了未被引用的组件与命令。

## 安全

- **浏览器接力连接上限**：桥最多同时处理 16 个连接，超出直接返回 503，避免本机程序刷连接把应用拖垮。
- **扩展身份校验**：`/add`、`/update.xml`、`/extension.crx` 只接受本应用扩展的 ID，其他 `chrome-extension://` 来源一律 403；此前任何扩展都能向应用投递链接。
- **拒绝超长请求体**：超过上限返回 413，不再静默截断后按残缺内容处理。
- **本机与内网地址**：浏览器接力与 `clouddownloader://` 深链接不再接受回环、内网、链路本地地址，避免被网页利用来探测本机服务。

## 稳定性

- **删文件与打开目录移出状态锁**：删除任务文件、打开下载目录不再持锁执行磁盘或 Shell 操作，界面与桥不会因此卡住。
- **下载引擎自愈**：aria2 意外退出后 30 秒内自动重启，并把受影响的任务标成「已暂停」等待恢复，不再出现界面看起来正常、实际所有请求都失败的状态。
- **轮询改为差量写库**：任务轮询每秒只读一次全表，且仅在字段变化时写库；任务多时不再出现每秒 N 次全表读写的卡顿。
- **单条坏记录不再拖垮全表**：任务与上传列表逐行容错，一行损坏只跳过该行。
- **设置保存使用事务**：13 项设置原子写入，中途失败不会留下半套配置。
- **本地文件夹选择加上限**：最多 2 万个文件、32 层目录，并用规范化路径防止目录联接成环导致界面冻结。
- **磁力解析不再占着锁等网络**：解析中的锁只保护任务表，取消按钮不会再卡顿，超时清理也不会被跳过。
- **上传任务收尾**：上传结束时清理运行标记，异常退出不会留下永远「进行中」的记录。

## 界面

- **首次加载失败不再卡住**：账户或接力横幅初始化出错时，界面仍会进入可用状态并显示错误。
- **搜索与轮询不再越权覆盖**：并发搜索只让最新一次结果落地，切换目录后旧轮询停止，搜索不会再永久转圈。
- **全选与计数一致**：全选只作用于列表里可见的任务，标题栏计数与左侧导航单位一致。
- **接力确认窗**：停在上传页时点「交给 CloudDownloader」也能立即入队；失败时横幅不会提前消失。
- **弹窗键盘操作**：扩展面板与接力确认窗支持 Esc 关闭，打开时聚焦、关闭后焦点还原。
- **扩展磁力接力**：浏览器扩展接管磁力链接时不再报「接力失败」。

## 清理

- 删除未被引用的组件（`DrivePanel`、`CloudDrivePanel`）、调试演示脚本、iOS/Android 模板图标，以及前端从未调用的 `settings_get` 命令。
- 夸克的下载域名校验复用统一实现，不再维护两份会漂移的副本。
- 便携包补上 `extension/` 目录，便携版「安装扩展」与扩展自更新不再 404。
- 验证记录重写为当前版本内容，`package.json` 补上 `test` 与 `test:ui` 脚本。

## 说明

- 浏览器接力扩展升到 0.2.2，已安装者会在扩展自动更新后生效；也可在设置页「浏览器扩展」里重新安装。
- 自动更新仅对 0.6.0 及之后的安装版生效；便携版与开发模式不会自我替换。
