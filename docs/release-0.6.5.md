# CloudDownloader 0.6.5

0.6.5 完善了「我的网盘」列表表头的交互：选中态批量操作并入表头行，列头可直接点击排序，并统一了普通态与选中态的表头尺寸与背景色。

## 更新内容

- 批量操作并入列表头：选中文件后不再出现独立的整行批量栏，而是在文件列表表头行内显示「全选 / 已选中 N 项 / 取消选中 / 下载 / 分享 / 删除 / 更多」，右侧仍保留「大小」「修改时间」列头，布局与 0.6.4 的参考样式一致。
- 表头尺寸与底色统一：普通态与选中态使用同一套表头样式，固定高度 48px、同一背景色，切换选中不再出现行高变化或底色跳变，仅内容不同。
- 列头点击排序：`文件名称`、`大小`、`修改时间` 三个列头均可点击。首次点击按默认方向排序（名称升序，大小 / 修改时间降序），再次点击切换升 / 降序，并显示 ⇅ / ↑ / ↓ 指示；点击排序按「全库」进行，不再只作用于当前页。
- 网格视图没有表头，选中时仍在顶部显示批量栏，功能不缺失。
- 其余 0.6.4 能力保持不变：行悬浮操作、排序 / 筛选面板、全库排序筛选、面包屑折叠、上传菜单、文件夹上传保留目录结构、迅雷新建文件夹、创建时间、下载文件夹后台解析。

## 说明

本版为界面交互优化，未改动网盘后端接口。批量操作现在是表头行的一部分，选中时表头高度、宽度与底色都和未选中状态一致；重命名与删除仍因后端接口未接入而置灰。
