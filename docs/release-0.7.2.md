# CloudDownloader 0.7.2

0.7.2 从根上解决「安装或升级时无法写入 `bin\aria2c.exe`」：下载引擎不再从安装目录运行，安装包也就不会再被一个正在运行的进程挡住。

## 修复

- **引擎改为在本地应用数据目录运行**：启动时把 `bin\aria2c.exe` 复制到 `%LOCALAPPDATA%\CloudDownloader\engine\aria2c.exe`（随版本自动刷新），从副本启动。安装目录里的那份只被读取、不会被长期占用，升级时可以随时覆盖。
- **安装器清理逻辑加强**：先关闭主程序，再按安装目录范围停止引擎，清掉可能存在的只读属性，并等待文件真正可写。仍然写不进去时会弹窗说明该退出什么，而不是抛一句「无法打开要写入的文件」，点「重试」可以再试一次。
- **安装日志**：全过程写到 `%TEMP%\clouddownloader-install.log`，包含安装前的进程列表，出问题时可以直接看出是谁占着文件。

## 说明

- 从 0.6.x / 0.7.0 / 0.7.1 升级时，旧版本的引擎仍在安装目录里运行，安装器会先把它关掉；升级到 0.7.2 之后就不存在这个问题了。
- 扩展没有变化，仍是 0.2.0。
